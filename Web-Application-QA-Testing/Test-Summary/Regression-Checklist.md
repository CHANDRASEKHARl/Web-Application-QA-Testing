# Regression Checklist

Use this checklist after a defect fix. Record the date, build or change reference, and results in the test summary report.

| ID | Workflow | Check | Status |
| --- | --- | --- | --- |
| RG-001 | Registration | A valid account can still be registered. | PASS |
| RG-002 | Registration | Email and password validation still reject invalid input. | PASS |
| RG-003 | Login | A registered user can log in successfully. | PASS |
| RG-004 | Dashboard | The dashboard displays the signed-in user's details. | PASS |
| RG-005 | Profile | A complete valid profile can be saved. | PASS |
| RG-006 | Logout | Logout ends the session and blocks protected pages. | PASS |
